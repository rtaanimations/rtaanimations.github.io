
# RTA Animations (Amazon-tagged)

Already configured with Amazon Associates tag: **rtaanimations-20**.

## Deploy
1) Make a repo named `YOURUSERNAME.github.io`.
2) Upload all files to the repo root.
3) If needed: Settings → Pages → Deploy from a branch → main.

## Customize
- Change `CANONICAL_BASE` in `/config.js` to `https://YOURUSERNAME.github.io` once the repo exists.
- Edit titles and descriptions in each HTML file if you want different wording.
- Replace `/assets/placeholder.png` with real images.
